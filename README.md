# Тест «Что мешает тебе брать от жизни всё?»

Квиз Юлии Мартынюк. Статическая страница без сборки: `index.html`, `quiz.js`, `quiz.css`.

Главная страница (`index.html`) — версия v10. Её и папки `v1`…`v10` собирает `python3 make_versions.py` из `template.html`; вручную `index.html` не править. Перед выкладкой менять `?v=` в `template.html`.

Все тексты и настройки — в `config.js` (вопросы, результаты, ссылка на лекцию, ID аналитики, тема).
Фото — `yulia.jpg`.

Страница публикуется через GitHub Pages из ветки `main`.
